# StruggleTAL
This is the code release for the reproduction of the experiments mentioned in the paper: [EvoStruggle: A Dataset Capturing the Evolution of Struggle across Activities and Skill Levels](https://arxiv.org/abs/2510.01362). 

The dataset used is [EvoStruggle](https://github.com/FELIXFENG2019/EvoStruggle/).
